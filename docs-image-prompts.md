# Docs pictures: prompts for ChatGPT

Run each prompt in the open ChatGPT chat, then save the image as the file name shown, into `public/docs/`
(JPG, any size; 3:2 crops best). The docs page at `/docs` shows each picture as soon as its file exists.
Keep the same chat so the look stays consistent.

Style line to keep in every prompt: *dark near-black cinematic scene, moody and painterly, soft volumetric light,
one electric lime-green accent glow, everything else charcoal and warm grey. No text, no letters, no logos.*
