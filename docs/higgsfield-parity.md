# Higgsfield, feature by feature

What Higgsfield's site offers (read from its navigation, Academy, Faceless
Studio and Content Factory pages), and where each piece lives in haggs. Everything
that generates runs through Comfy.

| Higgsfield | In haggs |
| --- | --- |
| AI Video | Video: a clip from words or a picture (MiniMax H3 and the rest of Comfy's video models) |
| AI Image | Photos → Make (FLUX 3) |
| Edit Image | Photos → Edit a photo (FLUX Kontext) and the photo apps on Workflows |
| Inpaint | Workflows → *Paint something into a photo*, *Remove something from a photo* |
| Upscale, Sora 2 Upscale | Workflows → *Make a photo sharper and bigger* (open weights), *Make a video sharper and bigger* |
| Mixed Media | Restyle in the editor: cel anime, claymation, scribble, pixel art, mixed media and more, from a style sheet |
| AI Face Swap | Swap, and *Swap a person in a video* (open-weights Wan Animate) |
| AI Influencer, Soul ID Character | Photos → Characters: traits or photos, a sheet, an identity lock sent with every shot |
| Apps | Workflows: 26 ready-made apps, build your own, your apps, Comfy's templates, Community |
| Cinema Studio | The Look panel (camera, lens, light, film, grade), the Reshoot dial, Locations |
| Marketing Studio | Workflows → Product and ads (ad sequence, 3×3 grid, product in hand, swap into an ad, mockups) |
| Lipsync Studio | Workflows → *Lip-sync a video to any voice*, and the editor's Voice and lip-sync |
| Fashion Factory | Workflows → Fashion (try on, flat lay to studio, editorial, outfit on a portrait, fashion video) |
| Photodump Studio | Workflows → *Photo dump from one photo* |
| Popcorn | Series pictures on one page; *Single image to multiple consistent shots* |
| Canvas | Workflows → Build your own: an open canvas, stack any workflow, swap any step's model |
| Academy | Academy: seven short lessons, homework, a certificate |
| Faceless Studio | Series → Faceless channel, with a narrator (ElevenLabs v3) |
| Content Factory | Series: What if, POV, Story, Did you know, Top 5, Influencer |
| MCP / CLI | `scripts/mcp.ts`: read projects, propose boards, series and canvases, search the workflow library |
| Katana (recreate edits with your content) | Video → Recreate an edit: a video model reads the reference's shots, then the board is rebuilt around your character |
| Community | Workflows → Community: publish free or up to 12¢ a run |

## Beyond Higgsfield

- Every price is on its button, in dollars, from Comfy's published node prices.
- Open-weights workflows are labelled, and run free on your own ComfyUI.
- Every project has Sheets → Board → Cut → Media: a script becomes a board, the
  board a cut, with every take kept.
- An editor with separate Video, Voice, Effects and Music tracks, undo, trim, a
  frame-fix tool and a reshoot dial.
- Claude can lay out your boards, series and canvases over MCP with no API key.
